Repositorio Guía de instalación Chuleta completa

Instalación segura y repetible. Puede ejecutar de nuevo el instalador después de actualizar el repositorio: conservará lo que ya esté correcto y añadirá lo que falte. No sustituye la configuración personal de Neovim, tmux o la terminal.

1. Primera instalación

Abra una terminal, copie el bloque completo y pulse Enter:

cd ~
git clone https://github.com/isaiasfl/entorno-nvim.git
cd entorno-nvim
./scripts/instalar-alumno.sh --perfil dwec --sistema

El instalador mostrará los paquetes que falten y pedirá confirmación antes de utilizar sudo. Incluye Node.js 24, npm, npx, Neovim, tmux y los servidores de lenguaje web. No instala Pandoc, PDF ni Chromium.

2. Abrir la carpeta de trabajo

mkdir -p ~/DWEC
cd ~/entorno-nvim
./bin/entorno-dev --perfil dwec --sin-ia ~/DWEC

Para abrir otro proyecto, sustituya ~/DWEC por la ruta de su carpeta. El entorno mostrará Neovim arriba y una terminal debajo.

3. Actualizar más adelante

cd ~/entorno-nvim
git pull
./scripts/instalar-alumno.sh --perfil dwec --sistema

Si aparece un error

Ejecute la comprobación y copie el mensaje completo de la terminal:

cd ~/entorno-nvim
./scripts/instalar-alumno.sh --perfil dwec --comprobar

Si Neovim parece bloqueado, pulse Esc. Tras una actualización, cierre la sesión antigua con Ctrl+a, suelte y pulse Q; después vuelva a abrir el proyecto.
