# Propuesta de identidad visual

El banner actual es legible, pero tiene muchos elementos y no proporciona un
símbolo independiente para iconos. La propuesta busca una marca propia; no
sustituye automáticamente el logo actual.

## Prompt para Nano Banana u otro generador

Diseña una identidad visual original para «entorno-nvim», un entorno de
programación y aprendizaje basado en Neovim y terminal. Debe transmitir
claridad, velocidad, control y cercanía: herramienta seria, accesible a quien
está aprendiendo. Crea un símbolo geométrico propio que combine sutilmente una
N, un cursor de terminal y la idea de un espacio de trabajo. No copies el logo
oficial de Neovim. Añade el nombre exacto «entorno-nvim» con tipografía sans
serif limpia y muy legible. Integra «IFL» como firma secundaria discreta.
Paleta: verde esmeralda y azul petróleo, con un acento cian moderado. Acabado
plano, estética vectorial, pocos trazos, excelente legibilidad en tamaños
pequeños. Sin robots, mascotas, cerebros, neón, efectos 3D, brillos ni fondos
recargados. Sin slogans ni textos adicionales. Composición horizontal para
cabecera de GitHub, mucho aire y márgenes seguros, símbolo a la izquierda y
nombre a la derecha. Fondo transparente. Entrega la composición horizontal
con proporción 4:1 y una versión separada del símbolo cuadrado, en alta
resolución. Debe funcionar sobre fondos claros y oscuros.

## Revisión antes de publicar

Comprobar el texto exacto y la legibilidad en móvil. Una imagen generada con
aspecto vectorial sigue siendo raster: para un SVG real habría que reconstruir
el símbolo y la tipografía. Evitar meter la versión del proyecto en el logo,
para no tener que regenerarlo con cada release.
