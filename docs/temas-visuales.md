# Diez temas para programar

Pulse `Espacio u t`, elija con las flechas y confirme con Enter. La selección se guarda para próximas sesiones; reinicie Neovim para cargar cambios del proyecto.

| Tema | Carácter |
| --- | --- |
| Catppuccin Mocha | Oscuro, tonos pastel; predeterminado. |
| Tokyo Night | Azul nocturno, colores vivos. |
| Kanagawa Wave | Azul oscuro y tonos inspirados en tinta japonesa. |
| Gruvbox Dark | Cálido, colores tierra y contraste marcado. |
| Rosé Pine | Morados y rosas suaves. |
| Everforest Dark | Verdes y tonos naturales. |
| Nightfox | Azul oscuro con colores equilibrados. |
| GitHub Dark | Aspecto familiar de GitHub. |
| One Dark | Inspirado en el clásico tema de Atom. |
| VS Code Dark | Paleta familiar de Visual Studio Code. |

Todos son oscuros; la comodidad depende de su pantalla, luz ambiental y gusto. Se cargan al seleccionarlos y sus versiones están fijadas en el lockfile. El color del terminal o de tmux puede depender de su configuración independiente.
